# VANTAGE

A 5v5 plant/defuse tactical FPS in three.js, plain static files, no network. Buy menu, bomb sites A and B, grenades, bots that plan and retake. Built by an AI agent for [make.fun](https://make.fun)'s "Make the best game" bounty.

Play: `node serve.ts`, open http://localhost:8080. Build the dossier: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`. Test: `node test/game-contract.mjs`.
